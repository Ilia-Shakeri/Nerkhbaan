- [پنل]: https://nerkhbaan.ir/admin/ . API پنل در `/api/admin/`.
- [ورود مدیر]: حساب و رمز مدیر پیشین حفظ. ثبت عامل دوم در بخش Security لازم؛ کدهای بازیابی خصوصی حفظ.

- [مهاجرت]: هشت نسخه ثبت. فایل‌های اعمال‌شده همان. مهاجرت هشتم در کپی و زنده؛ کاربر و صف قبل همان.

## مسیر اجرا

کد اجرا در worktree جدا زیر `/opt/Nerkhbaan/.releases/` است. مسیر `current` به نسخه تحویل وصل.
فایل راز در `/opt/Nerkhbaan/.env`؛ فایل `runtime.override.json` کنار کد اجرا. فایل راز چاپ یا وارد Git نشود.
نام پروژه Compose همان `nerkhbaan` است. ورودی مشترک در `/opt/edge/compose.json` است.

تصویرهای زنده با منبع آزموده‌شده:

| جزء | tag دقیق |
| --- | --- |
| دو API | `nerkhbaan-api:2.8.1-2c8c45b` |
| وب | `nerkhbaan-web:2.8.1-7402757` |
| پنل | `nerkhbaan-admin-web:2.8.1-7402757` |
| دریافت قیمت | `nerkhbaan-price-feed-pull:2.8.1-7402757` |

نام tag با `runtime.override.json` سنجیده شود. ورودی مشترک و تصویر پایگاه/Redis پیشین حفظ.
تعویض API با سه نمونه موقت انجام شد؛ پیش از حذف هر نمونه قدیم، نمونه تازه سالم. دو نمونه تازه باقی.
مهاجرت هشتم، چک readiness شماره ۵۰۳ داشت؛ جابه‌جایی بعد، یک ۵۰۲ دیده شد. زمان قطع دقیق سنجیده نشد.
پس از جابه‌جایی، شش چک HTTPS شماره ۲۰۰؛ دو API سالم. ۱۳ سرویس حفاظت‌شده، شناسه و زمان آغاز همان.
تعویض وب، پنل و دریافت قیمت در ۷٫۱۵۴ ثانیه سالم. ادعای بی‌قطع نداریم.

وضعیت خوانده شود:

```bash
cd /opt/Nerkhbaan/.releases/current
docker compose -p nerkhbaan --env-file /opt/Nerkhbaan/.env \
  -f docker-compose.prod.yaml -f runtime.override.json --profile admin ps
curl --fail --silent --show-error https://nerkhbaan.ir/api/health/ready
```

نشان درست: `release_version=2.8.1`، `status=ok`، `ready=true`، پایگاه و Redis هر دو `connected`.
نسخه مهاجرت `20261011_002_notification_sending_state.sql` باشد. صف، تازگی منبع و خطای تحویل در پنل دیده شود.
قیمت کهنه یا منبع قطع، قیمت زنده فرض نشود.

## نگهداری

- [اجرا]: دو API؛ تصویر هر جزء در override با tag دقیق بسته شود. `APP_IMAGE_TAG` تنها، این تحویل را شرح ندهد.
- [به‌روزرسانی]: نخست بکاپ، بازیابی و مهاجرت در کپی. سپس دستور محدود [راهنمای اجرا](release-operations.md). سرویس پایگاه و Redis بازسازی نشوند.
- [بازگشت]: با schema تازه، تصویر ناسازگار قدیم اجرا نشود. اصلاح رو به جلو ترجیح دارد. volume و AOF پاک نشوند.
- [بکاپ پنل]: تنها فایل وضعیت خواندنی mount شود. کل پوشه dump به API وصل نشود.
- [مرورگر نصب‌شده]: به‌روزرسانی وب پذیرفته شود. worker تازه مسیر پنل را از حالت آفلاین جدا کند.
- [راز]: کلید خصوصی Push روی سرور بماند. تنها کلید عمومی در وب ساخته شود.
- [شروع وب]: دانلود بسته در زمان شروع حذف. وب و پنل با حد CPU واقعی سرور آزموده شوند.
- [بکاپ رمز]: فایل کلید حفاظت‌شده و فایل‌های رمز روی دستگاه تحویل حفظ. بازکردن با همان پروفایل ویندوز سنجیده شد.

## صف و منبع

- [قیمت]: سلامت API، تازگی همه منبع‌ها نیست. چند ابزار تازه؛ برخی منقضی یا بی‌منبع. پنل زمان و علت دهد.
- [تاریخ]: صف قدیم حفظ. در سنجش ۱۱ اکتبر، ۱۳٬۰۴۰ کار خطای قدیمِ نبود منبع تاریخ داشت؛ ۱۸۷ کار خطای اولویت قیمت زنده. سیاست امروز ممکن فرق کند.
- [کار ناموفق]: ۹۲ کار ناموفق و ۳۹ retry قدیم دیده شد. علت و قدم بعد در پنل؛ حذف یا تکمیل ساختگی نشد.
- [رفع پوشش]: نخست منبع مجاز با مسیر تاریخ و واحد درست فعال؛ سپس retry محدود و سنجش ذخیره واقعی. داده فرضی افزوده نشود.
- [نوبت صف]: تنها کار با مسیر و سیاست فعال انتخاب. روشن‌شدن منبع یا تازگی قیمت، کار قدیم را باز قابل اجرا کند.

نصب NSIS بدون امضا، اجرای واقعی و حذف پاس؛ گواهی ناشر نداریم، نصب امضاشده پاس نیست.
همه ۳۹ مسیر منبع سنجیده شد؛ خوراک پیوسته بیرون و منبع مستقیم طلای۲۴/دلار نقد، کامل نیست.
بار کوتاه، هدف ۱۵ درخواست را نرساند؛ نیم‌ساعت پاس نیست. نتیجه تازه در [شاهد باقی](remaining-acceptance-2026-10-11.md).
