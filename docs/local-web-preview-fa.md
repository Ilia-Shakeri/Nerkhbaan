# مرور محلی وب نرخ‌بان — ۳۱اکتبر۲۰۲۶

نشانی روی همین رایانه: [بازکردن سایت محلی](http://127.0.0.1:43188).
نرخ و نمودار **نمونهٔ ساختگی** است و برچسب روشن دارد. مرور محلی، شاهد نرخ بازار، ارسال بیرونی یا تحویل عمومی نیست.

## شروع و توقف

در ریشهٔ مخزن:

```powershell
npm.cmd run preview:local
npm.cmd run preview:local:status
npm.cmd run preview:local:stop
```

نشانی بالا را باز کنید؛ حساب فقط‌آزمون بسازید و وارد شوید. رمز واقعی خودتان را به کار نبرید. هشدار بسازید، صفحه را بازخوانی کنید و ماندن هشدار را ببینید. دکمهٔ «ثبت اعلان نمونه در برنامه» پیام را برای همان حساب ثبت می‌کند؛ از زنگ بالای صفحه دیده می‌شود. این، دریافت اعلان روی گوشی یا سیستم‌عامل نیست.

حساب و هشدار پس از توقف و شروع دوباره می‌ماند. توقف فقط پردازه‌ها و ظرف متعلق به همین مرور را می‌بندد؛ حجم پایگاه پاک نمی‌شود. تنظیم خصوصی در `.local-preview` ساخته می‌شود؛ این پوشه وارد Git و تصویر برنامه نمی‌شود و نباید برای دیگران فرستاده شود. جای آن را عوض نکنید و حجم پایگاه را تا نیاز به دادهٔ آزمون حذف نکنید.

پیش‌نیاز: Python با وابستگی‌های API، Node/npm با وابستگی‌های وب، Docker در WSL و تصویر حاضر `postgres:17-alpine`. تصویر خودکار دریافت نمی‌شود. شاهد این دور مربوط به Windows/WSL است؛ راه‌انداز روی Linux از Docker محلی استفاده می‌کند ولی اجرای آن اینجا آزموده نشده.

## مرز داده و شبکه

| بخش | وضع |
| --- | --- |
| وب | فقط `127.0.0.1:43188`؛ گوشی و رایانهٔ دیگر به آن دسترسی ندارند |
| API | فقط `127.0.0.1:43187`؛ نوشتن فقط با مبدأ همان وب |
| PostgreSQL | فقط `127.0.0.1:55449`؛ پایگاه و schema علامت‌دار، حجم جدا و پایدار |
| ثبت‌نام، ورود، نشست، خروج، هشدار و پیام داخل سایت | مسیر واقعی برنامه روی پایگاه محلی جدا |
| نرخ و تاریخچه | نمونه با قرارداد فعلی API؛ مرجع بیرونی ناموجود می‌ماند |
| اعلان وب، تلگرام، ایمیل، پیامک و تماس | ارسال بیرونی خاموش؛ خدمت و رسید واقعی لازم است |
| مهاجرت و زیرساخت زنده | اجرا نمی‌شود؛ ساخت schema از ORM جای تست مهاجرت را نمی‌گیرد |

محیط والد و فایل تنظیم تولید خوانده نمی‌شوند. بکاپ نجات‌یافته، دادهٔ کاربران و کلید خارجی وارد این پایگاه نمی‌شوند. ظرف و حجم ناشناس رد می‌شود؛ فایل خصوصی از وب قابل خواندن نیست. سرویس‌های دیگر تغییر نمی‌کنند.

## تست

ابتدا مرور را بالا بیاورید؛ سپس:

```powershell
$env:PLAYWRIGHT_CHANNEL='chrome'
npm.cmd run test:local-preview
```

پنج تست قرارداد/محیط و یک سناریوی مرورگر واقعی محلی اجرا می‌شود: ثبت‌نام، رد نام نامعتبر، نرخ نمونه، هشدار پایدار، پیام داخل سایت، عرض باریک، خروج و ورود ایمیلی. حساب و هشدار آزمون در پایگاه محلی می‌ماند. دریافت بیرونی با پاسخ نمونه پاس نامیده نمی‌شود.

fixture اکنون `search_path` را برای pool جداگانهٔ درخواست هم تنظیم می‌کند؛ تست PostgreSQL مستقل هر سه موتور را می‌سنجد. تست پاک‌سازی fixture باید schema موقتِ جدا داشته باشد؛ هرگز schema پایدار مرور را به آن ندهید.

تحویل عمومی همچنان میزبان تازه، HTTPS، بازیابی بکاپ و کلیدها، نرخ معتبر، آزمون هشدار و رسید واقعی دستگاه می‌خواهد. [نقشهٔ تحویل و فلوچارت](project-completion-roadmap-fa.md). امضای ویندوز مانع تحویل وب نیست.
