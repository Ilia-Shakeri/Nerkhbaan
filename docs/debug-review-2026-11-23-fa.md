## روش بررسی

- ساخت وب، پنل و نمای دسکتاپ؛ نوع‌ها و بررسی ایستای پشت‌صحنه؛ سازگاری نسخهٔ ۲.۸.۱۹.
- تست پشت‌صحنه با محیط تعریف‌شدهٔ CI؛ اجرای پایگاه و Redis در ظرف‌های محلی جدا و بدون اتصال زنده. شانزده مهاجرت روی پایگاه آزمون اعمال شد؛ این، مهاجرت سرور نیست.
- گردش واقعی مرورگر روی API محلی: ورود/خروج، تغییر رمز و ابطال نشست، هشدار، پشتیبانی، نقش مدیر و مرز دو حساب. دادهٔ قیمت در پیش‌نمایش نمونه و دریافت بیرونی خاموش است.
- پنل در عرض‌های ۱۲۸۰، ۳۹۰ و ۳۲۰؛ وب در عرض‌های ۳۲۰، ۳۹۰ و ۱۲۸۰. آزمون موبایل مرورگر، دریافت اعلان روی گوشی واقعی نیست.
- رابط پیامک/تماس، سیاست هزینه، رضایت، جلوگیری از ارسال تکراری و راهنمای اعلان وب. هیچ پیامک، تماس یا ایمیل واقعی ارسال نشد.

## شکست‌های حفظ‌شده

اجرای خام تست‌ها با حق منبع پیش‌فرض، جای محیط آزمون تعریف‌شده نیست. اجرای پایگاه با نام بدون نشان آزمون رد شد؛ نگهبان نام دور زده نشد و پایگاه جدا با نام آزمون ساخته شد. تست نمونهٔ زمان به علت اختلاف ساعت شکست داشت و اصلاح بالا انجام شد.

تکرار تست ثبت‌نام روی پیش‌نمایشِ ماندگار به سقف هشت درخواست در ساعت خورد. فقط فرایند محلی دوباره شروع شد؛ داده و تنظیم محدودیت حفظ شد. حد امنیتی برای سبزکردن تست کم نشد.

اجرای چند مرورگر و کامپایل هم‌زمان، `ERR_INSUFFICIENT_RESOURCES` و قطع بارگیری بخش صفحه داد. شکست‌ها در رسیدها محفوظ‌اند؛ اجرای یکی‌یکی باید جدا ثبت شود. بالا بردن حد انتظار جای شاهد قبولی نیست.

## فرمان‌های توسعه

`npm.cmd run dev:all` محیط توسعهٔ دارای تنظیم محلی را اجرا کند؛ همهٔ پورت‌های بالا باید آزاد باشند و وابستگی‌های Python روی مفسر انتخاب‌شده نصب باشند. راه دیدن بدون کلید همان `npm.cmd run preview:local` است: وب `http://127.0.0.1:43188` و پنل `http://127.0.0.1:43189`. دادهٔ این پیش‌نمایش نمونه است.
