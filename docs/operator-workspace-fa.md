# ابزار اپراتور پس از انتقال پوشه — ۲۵اکتبر۲۰۲۶

<!-- delivery-docs:2.8.16 -->
> مرور سند: ۲۸اکتبر۲۰۲۶؛ منبع/سند **۲.۸.۱۶**، آخرین نصبِ پذیرفته **۲.۸.۱۵**. راهنما؛ وضع جاری در نقشه. عددها، شکست‌ها و قبولی‌های قدیم، شاهد تازه نیستند. [نقشهٔ جاری و فلوچارت](project-completion-roadmap-fa.md) · [فهرست سندها](documentation-index-fa.md).

- [محل جاری]: ریشه کد `D:\Projects\Nerkhbaan\repo`؛ رسیدهای پیشین در `delivery` و `delivery-desktop` کنار آن جدا مانده‌اند. فایل و هش تاریخی برای اصلاح مسیر بازنویسی نشود.
- [ابزار]: `scripts/operator_access.py` ریشه را از محل خودش پیدا می‌کند، هویت package را می‌سنجد و وجود دو پوشه مستقل تحویل را لازم می‌داند. اجرای مستقیم آن فقط مسیرها را چاپ می‌کند؛ شبکه یا حساب تازه نمی‌سازد.
- [Git و CI]: `release_control()` ابزار بررسی‌شده قدیم را بدون تغییر فایل بار می‌کند؛ هش آن ثابت و لازم است. فقط ROOT زمان اجرا و راه SSH با ابزار تازه بسته می‌شوند. خواندن منبع/CI مخزن دوباره از مسیر موجود کار می‌کند؛ اعتبار گیت در حافظه بماند. این اتصال، اجازه اجرای دوباره اسکریپت‌های مهاجرت یا بازیابی قدیمی نیست.
- [SSH]: هدف همان `deploy@87.248.130.63:9011` با StrictHostKeyChecking و BatchMode است. IPv4 محلی باید حاضر و قابل bind باشد؛ ابزار شبکه را عوض یا واسط دیگری را بی‌خبر انتخاب نمی‌کند. نشانی دیگر فقط پس از خواندن وضعیت سیستم به پارامتر `source_ip` داده شود. نبود نشانی، خطای هویت یا هش، توقف خواهد.
- [خطا]: هر دستور یک بار اجرا شود؛ مهلت و نتیجه نامعلوم تکرار خودکار ندارند. `OperatorCommandFailed.result` خروجی خصوصی را برای رسید نگه می‌دارد؛ چاپ معمول خطا مقدار خصوصی را نشان نمی‌دهد. اثر زنده یا قبولی، از exit0 تنها نتیجه نشود.
- [ثبت‌نام زنده]: `scripts/live-web-auth-smoke.mjs` از وابستگی همین مخزن استفاده می‌کند. پیش‌فرض، بدون اجازه صریح `--allow-production-signup` پیش از شبکه می‌ایستد. اجرای مجاز، یک حساب خودی می‌سازد، هیچ نامه‌ای نمی‌فرستد و ردّش در پایگاه می‌ماند؛ برای پایش دوره‌ای یا حساب مشتری مصرف نشود. رمز/کوکی در رسید نیاید؛ شکست پاک‌سازی هم نتیجه را false کند. رسیدها در `delivery/web-auth-smoke` جدا از Git هستند.
- [DNS]: `infra/compose.backend-dns.yaml` فقط قطعه DNS سرویس backend است؛ مستقیم جای override تصویر/محیط قرار نگیرد. با override بررسی‌شده ادغام و تفاوت نهایی باید تنها `backend.dns` باشد. استفاده از Docker DNS داخلی برای postgres/redis حفظ شود؛ DNS میزبان، خوراک قیمت و سرویس دیگر تغییر نکند. نصب فقط از نگهبان رسمی و با همان قفل‌های هویت، محیط، مهاجرت، تصویر و شواهد اپراتور انجام شود.
- [تست]: ۹ آزمون مسیر جابه‌جا، هویت اشتباه، نبود واسط، قفل SSH، خطای خصوصی، مهلت و هش ابزار تغییرکرده پاس؛ نام‌ها و importها هم سنجیده شدند. خواندن واقعی CI و اتصال SSH از محل تازه پاس بود. امتیاز همین ابزار پس از رفع،۹از۱۰؛ قبولی شبکه و دستگاه جداست.
