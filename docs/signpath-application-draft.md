## Application text

Nerkhbaan is a Persian market-price tracking application with a public web client,
a Windows desktop client and an administrator panel. It supports price history,
user-defined alerts, account/session management and optional administrator-managed
SMS and VoIP integrations. The service currently targets users in Iran.

The owner has authorized an MIT grant for owner-controlled original source code.
We preserve upstream licensing and notices. We are preparing dependency/asset
clearance and an installer privacy review; we do not claim these checks are
complete. Public source and existing release history are available in the repository.

We request review for the Foundation's free open-source signing program. The
proposed scope is the project's Windows executable and NSIS installer/uninstaller,
with immutable source/workflow/artifact provenance and manual approval for each
release. We understand that acceptance is discretionary, requires sufficient
verifiable project reputation and may require changes to the build/signing setup.

MFA enrollment and the proposed signing roles will be confirmed by the owner.
Please advise whether the current application architecture, installer disclosures
and proposed artifact scope qualify, and which remaining evidence is required.

## Submission boundary

The official entry point is https://signpath.org/apply. Its public page currently
embeds a HubSpot form. This draft does not certify that its table maps to every
required form field. Complete actual form fields honestly; don't assert cleared
rights, MFA or accepted signing before they exist. Supply contact details through
the official form or a private local file, never through versioned source changes.

The public operator notice contains an owner-approved contact address; that is
not proof the mailbox is currently reachable or enrolled at SignPath. No account
has been created and no email/application has been sent by preparing this draft.
