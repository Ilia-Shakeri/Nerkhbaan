# تحویل ۲٫۸٫۰ — ۲۰۲۶-۱۰-۱۱

موارد یافت‌شده و راه رفع. نتیجه آزمون نهایی در `delivery-readiness.md`.

- [قیمت]: وزن، عیار و ارز قاطی بود. ابزار مستقل و واحد دقیق نگه داشته شد.
- [نمودار]: تبدیل حدسی دلار به تومان بود. تاریخ واقعی هر ابزار خوانده شود.
- [منبع]: پاسخ کهنه راه fallback را می‌بست. تازگی هر پاسخ پیش از انتخاب بررسی شود.
- [تأیید]: منبع وابسته، شاهد مستقل بود. هویت و نقش شاهد بررسی شود.
- [کش]: ابزار خاموش هنوز قیمت داشت. سیاست زنده روی کش و پایگاه اعمال شود.
- [پخش زنده]: اتصال نو قیمت حذف‌شده را نگه می‌داشت. snapshot قیمت پیشین را پاک کند.
- [سقف اتصال]: اتصال ردشده هم snapshot می‌خواند. خواندن پس از پذیرش ظرفیت و Redis سالم.
- [ورود داده]: worker قدیم، داده نو را عقب می‌برد. lease، زمان و اولویت منبع قفل شود.
- [جهش قیمت]: داده مشکوک سریع قطعی می‌شد. شاهد مستقل و بررسی مدیر لازم شود.
- [تاریخ]: backfill به قیمت زنده می‌رسید. برچسب تاریخ و فیلتر زنده افزوده شد.
- [backfill]: پذیرش، ذخیره کامل شمرده می‌شد. شمار ذخیره واقعی و ادامه کار کنترل شود.
- [نوبت تاریخ]: کار بی‌مسیر نوبت کار مجاز را می‌گرفت. مسیر، سیاست و شرط قیمت پیش از claim بررسی؛ ردیف قدیم حفظ.
- [تاریخ]: حجم صفر رد می‌شد. صفر معتبر قبول؛ شکاف واقعی حفظ شود.
- [تلگرام]: عدد و واحد مبهم بود. parser صریح، شناسه درست و پیش‌نمایش افزوده شد.
- [هشدار]: ابزار، ارز و نوع ناسازگار می‌ماند. حالت کامل پیش از ذخیره بررسی شود.
- [هشدار]: هدف نامتناهی پذیرفته می‌شد. عدد مثبت و متناهی لازم شود.
- [صف ارسال]: لغو و retry هم‌زمان خراب می‌شد. تغییر وضعیت شرطی و attempt مستقل شود.
- [webhook]: بررسی DNS از اتصال جدا بود. اتصال به IP تأییدشده و مهلت محدود شود.
- [ورود]: حساب ناشناس زود پاسخ می‌داد. بررسی رمز ساختگی هم اجرا شود.
- [رمز]: تغییر رمز، نشست مدیر را زنده می‌گذاشت. نشست وب و مدیر با هم لغو شود.
- [بازیابی رمز]: کد کهنه می‌ماند؛ خطای ایمیل وضع را خراب می‌کرد. کد قبلی لغو؛ شکست ارسال rollback شود.
- [نوسازی نشست]: درخواست هم‌زمان، حساب را بیرون می‌انداخت. قفل، مهلت کوتاه تکرار و پاسخ ۴۰۹ افزوده شد.
- [خروج]: پاسخ دیررس ورود، حساب را زنده می‌کرد. نسل درخواست بررسی شود.
- [خروج]: ورود تازه با خروج قدیم تداخل داشت. درخواست ورود منتظر خروج بماند.
- [ویندوز]: خروج با access منقضی، refresh را زنده می‌گذاشت. refresh در بدنه خروج و لغو خانواده نشست افزوده شد.
- [محدودیت درخواست]: قطع Redis راه ورود را باز می‌گذاشت. در محیط اصلی بسته بماند؛ حافظه محلی سقف داشته باشد.
- [پنل]: صفحه کاربر و تاریخ امنیت ناقص بود. جزئیات، نشست، تغییر رمز، صفحه‌بندی و تاریخ افزوده شد.
- [نقش]: مجوزهای نقش خاص و آخرین مدیر امن نبود. مجوز دقیق، چند نقش و قفل آخرین مدیر افزوده شد.
- [امنیت مدیر]: عامل دوم و کد بازیابی کامل نبود. TOTP، منع تکرار و الزام ثبت افزوده شد.
- [پشتیبانی مدیر]: پاسخ با تیکت دیگر قاطی می‌شد. درخواست انتخاب و ارسال به شناسه ثابت وصل شود.
- [منابع مدیر]: تغییر سیاست به اجرا نمی‌رسید. نسخه، تعارض، برگشت و پیکربندی مؤثر افزوده شد.
- [پنل عملیات]: هشدار، صف مرده، backfill و پشتیبان کامل دیده نمی‌شد. کنترل و نمای مجاز افزوده شد.
- [تنظیمات مدیر]: scope و مقدار صفر گم می‌شد. خواندن مقدار مؤثر و بازنشانی دقیق شود.
- [ثبت عملیات]: فیلتر و اختلاف تغییر کم بود. صفحه‌بندی، اختلاف و خروجی افزوده شد.
- [گفتگو]: پاسخ دیررس به گفتگوی دیگر می‌رفت. بارگذاری و ارسال قفل؛ پاسخ درست با خطای فهرست پاک نشود.
- [Push]: نبود worker، خروج را معطل می‌کرد. انتظار محدود و وضعیت اشتراک واقعی شود.
- [ویندوز]: origin، مسیر فایل و فراخوانی پنجره امن نبود. پروتکل امن، مسیر محدود و بررسی فرستنده افزوده شد.
- [ویندوز]: چند نمونه روی نشست تداخل داشت. قفل یک نمونه و پروفایل مستقل آزمون افزوده شد.
- [migration]: TLS و قفل اجرا درست حفظ نمی‌شد. گزینه اتصال، مهلت و رد schema جدید افزوده شد.
- [حجم درخواست]: خطای چندلایه، پاسخ ۵۰۰ می‌داد. حجم بیش از حد، ۴۱۳ دهد؛ خطای دیگر پنهان نشود.
- [مدل پایگاه]: نوع JSON با PostgreSQL یکی نبود. نوع JSONB در PostgreSQL و JSON در SQLite شود.
- [اتصال پایگاه]: گزینه TLS در مسیر async خراب می‌شد. DSN کامل به driver داده شود؛ اتصال و فرمان مهلت داشته باشند.
- [Nginx]: آدرس container کهنه می‌ماند. DNS پویا و TLS بالادست درست شود.
- [شروع Nginx]: helper تازه وقت اجرا به مخزن بسته می‌رفت. helper حذف؛ listener صریح حفظ؛ شروع بدون دانلود بسته.
- [استقرار]: شبکه stage با محیط اصلی تداخل داشت. subnet مستقل و proxy مورد اعتماد دقیق شود.
- [restore]: هدف موجود ممکن پاک شود. هدف تازه لازم؛ داده، chunk و policy پس از restore مقایسه شود.
- [نصب]: قفل وابستگی و بسته آسیب‌پذیر بود. قفل نو، نصب تمیز و اسکن بسته افزوده شد.
- [CI]: آزمون مرورگر فقط فهرست می‌شد. سناریو واقعی اجرا؛ build، restore و بسته ویندوز دروازه شوند.
- [سند]: نسخه و API کهنه بود. نسخه ۲٫۸٫۰، قرارداد تولیدشده و راهنمای پنل نو شد.
- [تحویل]: فایل اجرا و راز ممکن همراه سورس رود. ZIP با حذف داده خصوصی و manifest هش ساخته شود.
- [بسته سورس]: SQL آغاز پایگاه جا می‌ماند. فایل آغاز دقیق و migration معتبر حفظ؛ dump ناشناس حذف شود.
- [تصویر اجرا]: بسته OS و Go کهنه بود. تصویرها نو؛ اسکن هفت جزء بدون کاهش گارد پاس.
- [ساخت]: فایل راز و cache ممکن به context رود. گارد context ریشه، API و تلگرام افزوده شد.
- [آزمون Nginx]: ابزار گواهی داخل تصویر نبود. گواهی روی runner و نام backend در fixture افزوده شد.
- [مسیر پنل]: دامنه جدا DNS نداشت. مسیر build قابل تنظیم؛ رابط روی `/admin/` هم کار کند.
- [وب آفلاین]: worker، پنل را صفحه عمومی می‌کرد. مسیر `/admin` و زیرمسیر آن جدا شد.
- [restore]: کار پاک‌سازی، ردیف بازیابی را پیش از سنجش پاک می‌کرد. همه کارهای کاربر در کپی متوقف؛ ۴۷ جدول دوبار برابر.
