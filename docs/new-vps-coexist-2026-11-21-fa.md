## HTTPS و منابع میزبان

- مالک ابر رکورد اصلی `@`، پروتکل مبدأ HTTPS و پیش‌فرض HTTPS آروان را روشن کرد. IP مبدأ همان مقصد نو است. برای این کار کلید API یا خرید لازم نشد. رکوردهای `www`، `git` و `cdn` در این دور تغییر نکردند.
- HTTP به HTTPS می‌رود؛ HTTPS بدون حلقه باز می‌شود. فقط نشانی‌های منتشرشدهٔ آروان برای IP اصلی کاربر قابل اعتمادند؛ هدر جعلی از مسیر مستقیم قبول نیست. پاسخ احراز هویت `no-store` و در CDN از کش کنار است.
- تنها سرویس مستقلِ مزاحم پورت ۴۴۳، پس از بکاپ بیرون سرور و با اجازهٔ صریح مالک متوقف شد. `x-ui`، Nginx میزبان و تنظیم‌های پروژه‌های دیگر محفوظ‌اند.
- درگاه نرخ‌بان روی عمومی ۴۴۳ و HTTP داخلی `127.0.0.1:18081` است. Nginx میزبان پورت ۸۰ را برای چالش گواهی و هدایت و ۸۴۴۳ را برای هدایت لینک قدیم نگه می‌دارد.
- یک API با سقف ۱۹۲MiB، پایگاه ۵۱۲MiB و مجموع سقف پایدار ۸۸۸MiB؛ بودجهٔ اتصال پایگاه چهار اتصال همگام، شامل دو اتصال محفوظ درخواست است. حاشیهٔ میزبان حداقل ۵۱۲MiB و فضای ریشه بیش از ۳GiB شرط است. این عدد، ظرفیت نامحدود نیست.
- گواهی مبدأ تمدید شد. چالش عمومی، تمدید آزمایشی پس از CDN و کلید/نام گواهی پاس شد؛ گواهی لبه و مبدأ جدا هستند. تایمر تمدید فعال است.
