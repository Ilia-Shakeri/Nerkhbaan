مقصد `141.11.107.84:9011`، نام میزبان `nerkhbaan`، وب `https://nerkhbaan.ir` و پنل `https://nerkhbaan.ir/admin/` است. مالک، تغییر IP آروان را دستی انجام داده و توقف سرویسِ مزاحم پورت ۴۴۳ را صریحاً مجاز کرده است. داشتن HTTP 200 به‌تنهایی، تحویل را ثابت نمی‌کند.

## طرح فعلی

- تنها `xray.service` مستقل، پس از کپی و تطبیق بکاپ بیرون سرور، متوقف و غیرفعال شد. `x-ui`، تنظیم دامنه‌های دیگر و وب‌سرور میزبان حفظ شدند.
- درگاهِ محدودِ نرخ‌بان، پورت عمومی ۴۴۳ را می‌گیرد. راه HTTP داخلی آن فقط `127.0.0.1:18081` است. وب‌سرور میزبان، پورت ۸۰ برای چالش گواهی و هدایت، و ۸۴۴۳ برای هدایتِ لینک قدیم دارد.
- مقادیر خصوصی: `INITIAL_HTTP_BIND=127.0.0.1:18081`، `INITIAL_TLS_BIND=0.0.0.0:443`، `PUBLIC_ORIGIN=https://nerkhbaan.ir` و `ADMIN_ORIGIN=https://nerkhbaan.ir`.
- `ACME_WEBROOT=/var/www/letsencrypt` میان میزبان و درگاه مشترک و فقط‌خواندنی است. هر دو HTTP و HTTPS مسیر چالش دارند. `scripts/initial_tls_deploy.py` نام، زنجیره و کلید گواهی، مالک استقرار، و گواهی واقعی پورت‌های ۴۴۳ و ۸۴۴۳ را می‌سنجد. نسخهٔ قبلِ گواهی حفظ می‌شود.
- پس از این تغییر، چالش هر دو مسیر و تمدید آزمایشی واقعی پاس شد: `remote_public_acme-20261121T104127826917Z.private.json`. این رسید، تحویل برنامه یا دریافت اعلان نیست.
