# نسخهٔ سند و منبع — ۲.۸.۱۶

تاریخ: ۲۸ اکتبر ۲۰۲۶. این نسخه، سند و هویت منبع را یکدست می‌کند؛ نرخ تلگرام را پیاده نمی‌کند و نصب زندهٔ تازه ندارد. نسخهٔ نصب‌شدهٔ پذیرفته **۲.۸.۱۵** با منبع `228ca5868d90686bb0a476f93179afead83d474a` است. [رسید نصب، داده و محدودیت‌ها](pricing-release-2.8.15-fa.md).

## تغییر

- نقشهٔ جاری با دو فلوچارت: [پایان پروژه و تحویل](project-completion-roadmap-fa.md). قیمت کانال و گروه تلگرام، کارِ بازِ لازم است؛ با پیام‌رسانی ربات یکی نیست.
- راه اتصال از روی کد اصلاح شد: [راهنمای تلگرام](telegram-ingestion-guide-fa.md). متغیرِ بی‌مصرفِ فهرست کانال، نشست حساب، منبعِ پایگاه، حق مصرف، نوع گروه و کمبودهای بازیابی/حذف روشن‌اند.
- راهنماهای فعال، نسخهٔ زنده، دامنهٔ ایمیل، اولویت وب و بکاپ مستقل را روشن می‌کنند. گزارش قدیم، شکست و عدد خود را حفظ می‌کند. [فهرست همهٔ سندها](documentation-index-fa.md).
- پنج بستهٔ پروژه، lockfile، `VERSION`، برچسب وب و نسخهٔ API برابر شدند. قرارداد و ۱۲۶ مسیر API از برنامه بازساخته شد؛ رفتار مسیرها تغییر نکرد.
- حقوق قلم‌ها و مجوزهای شخص ثالث حفظ شدند؛ فایل خصوصیِ محلی به Git افزوده نشد.

## سنجش

سازگاری نسخه و بازسازی قرارداد API پاس؛ ۱۳۰ تست رابط و ۲۸ تست worker پاس، بدون پرش. این‌ها تست کد و بدل‌اند؛ دریافت پیام واقعی تلگرام یا اعلانِ دستگاه را ثابت نمی‌کنند. پیوندهای افزوده، پوششِ فهرست سند، حفظ متن حقوقی و فرقِ کد با نصب باید پیش از تگ سنجیده شوند. CI باید روی همان منبعِ نسخه پاس شود؛ رسید اجرا با همان شناسهٔ منبع در بخش Actions مخزن دیده شود. تگ فقط پس از قبولی ثبت شود؛ نتیجهٔ CI نسخه‌های پیش، جای آن نیست.

## باز

قیمتِ واقعی تلگرام، پایش پیوستهٔ نرخ، رسید پوش سه دسته دستگاه، کپی بکاپ در مقصد مستقل، خدمت و رسید پیامک/تماس/ایمیل و پذیرش کارفرما بازند. SignPath رایگان رد شده؛ امضای ویندوز جداست. «پایان کل پروژه» از این نسخه نتیجه نمی‌شود.
