# آمادگی منبع وب و تحویل — ۳۱اکتبر۲۰۲۶

دامنه این دور، کد وب و نقشهٔ تحویل است. سرور جایگزین، دستگاه و خدمت بیرونی حاضر نشده‌اند؛ نصب زنده یا دریافت واقعی در این دور انجام نشد. نسخهٔ منتشرشده۲.۸.۱۹و برچسب آن تغییر نکردند؛ این اصلاح‌ها منتشرنشده‌اند.

## تغییر

- خواندن `PushManager.getSubscription()` هنگام همگام‌کردن اشتراکِ آغاز برنامه بیرون از مهار خطا بود. پس از خرابی ذخیرهٔ مرورگر، Promise رد می‌شد و فراخوانی بی‌انتظارِ آغاز برنامه خطا را نمی‌گرفت. خواندن و ثبت داخل همان مهار قرار گرفتند؛ تلاش بعدی همچنان کار می‌کند و اجازهٔ اعلان ناخواسته درخواست نمی‌شود. خطای اقدام صریح کاربر همچنان به رابط می‌رسد.
- ورود تا پایان وارسی نشست/خروجِ آغاز صفحه بسته می‌ماند؛ اکنون متن انتظار و `aria-busy` هم وضع را نشان می‌دهند. کنترل لغو ورود در خروج حفظ شد.
- نقشه، شرط‌های تحویل نخست وب، تحویل کامل، صاحب هر اقدام و کلیدهای لازم را جدا و با فلوچارت روشن می‌کند. هیچ قابلیت خواسته‌شده حذف نشده.

جمع آزمون‌های مرورگر۴۹است؛ آزمون‌های API در این دور دوباره اجرا نشدند چون API تغییر نکرد. نتایج قدیمی CI، شاهد CI تازهٔ این منبع نیستند.

تستِ خرابی ذخیرهٔ اشتراک پیش از اصلاح رد شد؛ پس از اصلاح، خرابی خواندن، خرابی ثبت و تلاشِ موفق بعدی را می‌سنجد. دو تلاش نخست مرورگرِ رابط و راهنمای اعلان، خطای `ERR_NETWORK_CHANGED` در ردّ اجرا داشتند؛ شکست و trace حفظ شد و اجرای تازه پاس شد. دو سنجش متن انتظار نیز نخست رد شدند: fixture فقط خواندن نخست را نگه می‌داشت؛ آغاز دوبل می‌توانست زودتر به خروج برسد. گیتِ fixture برای همهٔ خواندن‌های آغاز اصلاح شد؛ همان۱۵تست دوباره پاس شدند. شکست‌های نخست، پاس نامیده نشوند.

رسیدها و هش فایل‌های کدِ سنجیده‌شده بیرون Git در `D:\Projects\Nerkhbaan\delivery\web-initial-handoff-20261031\validation.json` و log/traceهای همان پوشه‌اند. این فایل‌ها نشانی اشتراک واقعی یا کلید ندارند.

## تکمیل محلی بدون کلید — دور دوم همین روز

[مرور محلی](local-web-preview-fa.md) با پایگاه جدا و پایدار بالا آمد. ورودی نام کاربری برای قواعد جدید مرورگر اصلاح شد؛ خط تیره باید escape شود تا نام نامعتبر واقعاً رد شود. پاسخ نرخ و نمودار محلی، ساختگی و با برچسب است. ثبت‌نام، ورود، ذخیرهٔ هشدار و پیام نمونهٔ داخل سایت از مسیر واقعی API و PostgreSQL می‌گذرند. `search_path` موتور درخواست نیز به schema جدا محدود شد.

| بررسی تازه | نتیجه |
| --- | --- |
| قراردادها و اجرای رابط | ۱۳۱پاس، صفر شکست و skip |
| مرورگر با پاسخ‌های کنترل‌شده؛ رابط، نشست، حق منبع، تنظیم اعلان، هشدار در دو اندازه | ۴۹پاس |
| مرورگر با API و پایگاه محلی واقعی | ۱پاس؛ حساب، نرخ نمونه، هشدار، پیام داخل سایت، خروج و ورود ایمیلی |
| قراردادهای محیط/نرخ نمونه | ۵پاس |
| fixture و سه موتور پایگاه، PostgreSQL واقعی | ۵پاس، صفر skip؛ این آزمون schema موقت جدا را پاک می‌کند |
| توقف/شروع | شمار و شناسهٔ ردیف‌های حساب، هشدار و پیام پیش/پس یکسان |
| ساخت وب و وارسی ایستای Python | پاس |

شکست‌های دور دوم نگه داشته شدند: تلاش‌های نخست مرور محلی روی انتظار ثبت‌نام، عنوان دقیق کارت و ترتیب مسیرهای نمونه رد شدند؛ اصلاح ورودی و اولویت مسیر، سپس locator عنوان واقعی، سناریو را پاس کرد. آزمون SQL/ORM ابتدا از حق مصرف منبع ساختگی رد شد؛ فقط همان فراخوانی ساختگی با حق خاموش سنجیده می‌شود و تنظیم پس از آن برمی‌گردد؛ این شاهد حق مصرف نیست. اجرای هم‌زمان مجموعه‌های مرورگر، فایل trace را با پاک‌سازی پوشهٔ مشترک حذف کرد؛ اجرای نهایی با خروجی جدا و پشت‌سرهم پاس شد. یک آزمون تنظیم اعلان در تلاش نخست timeout داشت؛ اثر اجرای هم‌زمان محتمل است، اما علت قطعی از trace حذف‌شده معلوم نیست. همان سه آزمون در اجرای جدا پاس شدند.

رسیدهای تازه، logهای شکست/پاس، نگه‌داری ردیف‌ها و هش منبع در `D:\Projects\Nerkhbaan\delivery\local-web-preview-20261031` است. امتیاز دامنهٔ کار محلی۹از۱۰؛ زیرساخت عمومی، مهاجرت واقعی، منبع تازه و رسید دستگاه امتیازدهی یا قبول نشده‌اند. برچسب۲.۸.۱۹و تصویرهای قدیم تغییر نکرده‌اند.
