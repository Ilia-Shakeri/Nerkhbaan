- [رسید مرورگر]: انتظار واقعی 60 ثانیه. `getNotifications()` خالی. عنوان تست در پنجرهٔ بومی Windows دیده نشد. مدرک نمایش یا تحویل Push نداریم. عدد 62276 میلی‌ثانیه فقط سقف زمان مشاهده است؛ زمان تحویل موفق نیست.
- [شبکهٔ سرور]: همهٔ Aهای دیده‌شده برای همان میزبان WNS، و نشانیِ درستِ تأییدشده روی Windows آزموده شد. AAAA نبود. API و شبکهٔ میزبان هر دو روی TCP 443 قطع؛ درخواست با نام میزبان و SNI درست، بررسی گواهی فعال، مسیر `/`، بدون کلید یا توکن. DNS تنها راه حل نشد. شاهد: `notification-wns-routes-target.json` و `notification-wns-routes-target-host.json`.
